# MemoBTP 🚧

MemoBTP est un outil SaaS conçu pour aider les entreprises du BTP à répondre plus rapidement et efficacement aux appels d’offres publics.

L’objectif est de générer automatiquement des **mémoires techniques** à partir d’un document d’appel d’offres, afin de faire gagner du temps aux entreprises et d’améliorer leurs chances de remporter des marchés.

---

## 🚀 Problème

Les entreprises du BTP passent énormément de temps à :
- Lire et analyser les appels d’offres
- Rédiger des mémoires techniques longs et complexes (20 à 80 pages)
- Réutiliser et adapter des anciens documents
- Respecter des contraintes techniques strictes

👉 Cela prend du temps et peut faire perdre des opportunités.

---

## 💡 Solution

MemoBTP simplifie ce processus :

1. Upload du PDF de l’appel d’offres  
2. Ajout des informations de l’entreprise  
3. Génération automatique d’un mémoire technique structuré  

👉 Résultat : gain de temps + meilleure qualité des dossiers

---

## ⚙️ Fonctionnalités (MVP)

- Landing page de présentation
- Formulaire de capture de prospects
- Base de données Supabase (prospects)
- Connexion Vercel (déploiement)
- Système de liste d’attente

---

## 🧪 Objectif actuel

Ce projet est un **MVP (Minimum Viable Product)** visant à :
- Tester l’intérêt réel du marché BTP
- Collecter des premiers prospects
- Valider la demande avant développement complet du SaaS

---

## 🛠️ Stack technique

- Frontend : Next.js (App Router) / TypeScript / Tailwind CSS
- Backend : Supabase
- Hosting : Vercel
- Auth / DB : Supabase PostgreSQL

---

## 📊 Modèle futur (en cours)

- SaaS B2B pour entreprises du BTP
- Génération automatique de documents d’appels d’offres
- Abonnement mensuel + crédits par document
